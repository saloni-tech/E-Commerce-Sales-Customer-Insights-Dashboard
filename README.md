# 📊 Madhav Ecommerce Sales Dashboard (Power BI)

## 🔍 Project Overview
This project is an interactive **Power BI dashboard** built to analyze e-commerce sales data and extract meaningful business insights.  
It helps stakeholders understand **sales performance, profit trends, customer behavior, and category-wise distribution** across different quarters.

---

## 🚀 Key Insights
- 📈 Total Sales, Profit, Quantity, and Average Order Value (AOV)
- 🗺️ State-wise sales performance
- 🛍️ Category & sub-category contribution
- 💳 Payment mode distribution (COD, UPI, Cards, EMI)
- 📅 Monthly & quarterly profit trends
- 👥 Top customers by sales

---

## 🧩 Dashboard Features
- Dynamic **Quarter-wise filtering (Q1–Q4)**
- Interactive charts & slicers
- Clean and modern dark-theme UI
- Business-ready KPIs for decision-making

---

## 🛠️ Tools & Technologies
- **Power BI**
- Data Modeling
- DAX Measures
- Data Visualization
